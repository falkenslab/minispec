# Engineering principles

Consult **before** writing code.

- Solve first, optimize later.
- Readable code over clever code.
- One responsibility per class or component.
- Prefer composition over inheritance.
- Avoid premature abstractions.
- Preserve existing behavior.
- Don't refactor outside the task's scope.
- If a choice adds a lot of complexity, propose a simpler alternative first.
- Document decisions, not implementation.
